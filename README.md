# SiteX Post

Nền tảng SaaS AI SEO tự động cho WordPress.

- **SiteX Post Cloud** — backend Laravel 13 (`backend/`) + SPA Vue 3 (`frontend/`)
- **SiteX Post** — plugin WordPress (`wordpress-plugin/sitex-post/`)

> Trạng thái: **Phase 0 — thiết kế hoàn tất**. Mã nguồn ứng dụng sẽ được tạo ở Phase 1.
